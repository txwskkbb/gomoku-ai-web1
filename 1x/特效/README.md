# 纹样发光织物特效

这是一版按照参考视频重做的本地网页特效：黑底、发光织物平面、经纬网格、边缘拉丝、扫描光和缓慢透视旋转。

运行：

```bash
cd /Users/arius/1x
python3 -m http.server 4173
```

Windows 一键启动：

- 双击 [`start.bat`](/Users/arius/1x/特效/start.bat)

停止：

- 双击 [`stop.bat`](/Users/arius/1x/特效/stop.bat)

打开：

```text
http://127.0.0.1:4173/特效/
```

操作：

- 右上角下拉框选择图片
- 拖拽旋转视角
- 滚轮缩放
- 双击或按 `R` 重置视角
